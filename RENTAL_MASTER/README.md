# RENTAL_MASTER

## Overview
RENTAL_MASTER is a comprehensive management system built on the MAIN HUB platform.

## Features
- Full CRUD operations
- Authentication & Authorization
- Multi-company support
- Integration with MAIN HUB

## Structure
```
RENTAL_MASTER/
├── backend/
│   ├── src/
│   │   ├── config/
│   │   ├── controllers/
│   │   ├── models/
│   │   ├── routes/
│   │   ├── middleware/
│   │   └── utils/
│   ├── package.json
│   └── .env
└── frontend/
    ├── src/
    │   ├── pages/
    │   ├── components/
    │   ├── services/
    │   └── App.js
    ├── public/
    └── package.json
```

## Setup
1. Install backend: `cd backend && npm install`
2. Install frontend: `cd frontend && npm install`
3. Run backend: `npm run dev`
4. Run frontend: `npm start`
